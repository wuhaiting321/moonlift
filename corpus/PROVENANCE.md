# Corpus provenance

Every `.wasm` under `corpus/` is listed here. A file without an entry here is not allowed to stay
in the repository — that is the rule from `NOTICE`.

Populated at stage S9 with three sources:

| Source | How it is produced | Why it is trusted |
|---|---|---|
| `generated/` | `tools/gen_corpus` compiles small MoonBit programs with `moon build --target wasm` | real compiler output, source known, expected values computable |
| `handwritten/` | `.wat` files assembled with wabt's `wat2wasm` | covers instruction corner cases a compiler never emits |
| `external/` | public artifacts, only with URL + license + SHA-256 recorded below | realistic size and structure |

Template for each entry:

```
corpus/<path>
  origin:  generated by tools/gen_corpus from corpus/src/<name>.mbt
  command: moon build --target wasm
  license: Apache-2.0 (this repository)
  sha256:  <hash>
  notes:   exercises i64 division, block nesting depth 4
```
